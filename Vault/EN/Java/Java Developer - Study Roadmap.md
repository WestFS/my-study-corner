### Backend Developer - Beginner

A beginner developer must master the very basics:

- [ ] **Basic OOP**
    
    - [ ] Getters, setters, and constructors
        
    - [ ] Basic inheritance (e.g., understand how to create a `Fish extends Animal`)
        
    - [ ] `final` classes, methods, and fields
        
    - [ ] Access modifiers: `protected`, `public`, and `private`
        
- [ ] **Static Members**
    
    - [ ] Static methods, classes, and fields
        
- [ ] **Control Flow**
    
    - [ ] `if`, `else`, and `else if`
        
    - [ ] `foreach` (for)
        
    - [ ] `while`
        
- [ ] **Types and Data Structures**
    
    - [ ] Numeric types like `Double`, `Float`, `Integer`
        
    - [ ] Primitive types basics (`int`, `float`, `double`)
        
    - [ ] Arrays
        
- [ ] **Exception Handling**
    
    - [ ] Throwing exceptions with `throw`
        
    - [ ] `try`, `catch`, and `finally` blocks
        
- [ ] **Method Fundamentals**
    
    - [ ] Method parameters
        
    - [ ] Return statements: `return null;`, `return value;`, `return;`
        

**Core Practices:**

- **NEVER** create fields without an explicit access modifier. Always prefer `private String text = "";` over `String text = "";`.

- Use `final` whenever possible.

### Backend Developer - Intermediate

_This is where many give up. If you've reached this level, you’re more advanced. But you must learn these to earn a seat at the adult table._

**Note:** The more advanced you become, the less `static` you use. Top Java developers aim to use ZERO `static`—you don’t need it.

- [ ] **Tools**
    
    - [ ] Knowledge of Git/GitHub
        
    - [ ] Familiarity with a build tool (Maven or Gradle)
        
- [ ] **Advanced OOP**
    
    - [ ] Interfaces and their utilities
        
    - [ ] `record` classes
        
    - [ ] `final` method parameters
        
    - [ ] Sealed classes
        
    - [ ] Abstract methods in abstract classes
        
    - [ ] Utility classes (helper classes)
        
    - [ ] `import static`
        
- [ ] **Annotations**
    
    - [ ] Understand `@Deprecated`
        
    - [ ] Master `@Override`
        
    - [ ] Stop suppressing warnings with `@SuppressWarnings` or similar hacks
        
- [ ] **Clean Code**
    
    - [ ] Basic JetBrains annotations (`@NotNull`, `@Nullable`, `@Range`)
        
    - [ ] Early return technique
        
- [ ] **Custom Exceptions**
    
    - [ ] Create your own `Exception` classes
        
    - [ ] Understand the concepts of `Error`, `Throwable`, `RuntimeException`
        
    - [ ] Study existing exceptions, like `NullPointerException` and `IllegalStateException`
        
- [ ] **Java Reflection**
    
    - [ ] Learn how to access private methods or fields
        
- [ ] **Databases**
    
    - [ ] Intermediate knowledge of MySQL and SQLite (SQL in general)
        
- [ ] **Libraries and Core APIs**
    
    - [ ] Master native Java classes to avoid reinventing the wheel
        
    - [ ] **Generic Types**
        
        - [ ] Generic methods like `public final <T> T getValue()`
            
        - [ ] Unknown generic type `?`
            
    - [ ] **Date and Time API** (`Date`, `OffsetDateTime`, `Duration`, `Instant`, `ZonedDateTime`, `LocalDateTime`)
        
    - [ ] **JSON** (Google's GSON, Jackson, etc.)
        
    - [ ] **File handling** (`InputStream` and `OutputStream`)
        
    - [ ] `java.util.Optional`
        
    - [ ] `java.util.function` (`Consumer`, `Predicate`, `Supplier`)
        
    - [ ] **Collections**
        
        - [ ] Understand the difference between `Set<T>` and `List<T>`
            
        - [ ] Use `Map<K, V>`
            
    - [ ] **Code Optimization with Streams**
        
        - [ ] `Stream#filter`
            
        - [ ] `Stream#map`
            
        - [ ] `Stream#anyMatch`
            
    - [ ] **Serialization**
        
        - [ ] Understand the `Serializable` interface
            
    - [ ] **Networking Basics**
        
        - [ ] Basics of `Socket` and `Channel`
            
    - [ ] `UUID`
        
- [ ] **Object-Oriented Fundamentals**
    
    - [ ] Override `equals()` and `hashCode()` correctly
        
- [ ] **Foundational Knowledge**
    
    - [ ] Basics of cryptography (`MD5`, `SHA-256`)
        
    - [ ] Intermediate/advanced mathematics (e.g., sine, cosine, tangent)
        
    - [ ] Basic knowledge of regex
        
- [ ] **Practice**
    
    - [ ] Practice, lots of practice.

### Backend Developer - Advanced

_If you’ve made it here, congratulations! Your knowledge is impressive and rare. Welcome to the final boss!_

- [ ] **Testing**
    
    - [ ] Total mastery of testing environments (e.g., mastering the `org.junit.Test` annotation)
        
- [ ] **Low-Level Java**
    
    - [ ] Total control over byte manipulation (operators like `|`, `&`, `~`)
        
    - [ ] Understand the `volatile` keyword
        
    - [ ] Understand the `native` keyword in Java
        
    - [ ] Runtime library loading/unloading
        
- [ ] **Advanced Cryptography**
    
    - [ ] AES/ECB
        
    - [ ] AES/CBC, AES/GCM, and related concepts (understand Initialization Vectors)
        
- [ ] **Build and Deployment**
    
    - [ ] Create your own Maven repository
        
- [ ] **Advanced Annotations**
    
    - [ ] Master advanced annotations (e.g., JetBrains' `@Contract`)
        
    - [ ] Create custom annotations
        
    - [ ] Build your own Annotation Processor
        
    - [ ] Use `@FunctionalInterface`
        
- [ ] **Multi-threading and Concurrency**
    
    - [ ] `Thread` and `Runnable`
        
    - [ ] Advanced knowledge of `AtomicInteger`, `AtomicBoolean`, etc.
        
    - [ ] Use of `synchronized`
        
    - [ ] `CompletableFuture` and `ExecutorService`
        
- [ ] **Advanced Rendering (if applicable)**
    
    - [ ] `JPanel`, `JFrame`, `Graphics`, `Graphics2D`
        
    - [ ] Render complex 3D objects on a 2D screen
        
- [ ] **API Mastery**
    
    - [ ] Master integration with external APIs (Rest APIs, Socket APIs)
        
- [ ] **JVM Ecosystem**
    
    - [ ] Basic web development with Java
        
    - [ ] Build code outside Java but compatible with the JVM (e.g., Scala, Kotlin)
        
- [ ] **Architecture and Best Practices**
    
    - [ ] More interfaces than classes in your code
        
    - [ ] ZERO `static` usage (optional but common in advanced projects)
        
    - [ ] Writing the cleanest code using the best practices
        
- [ ] **Advanced Data and Protocols**
    
    - [ ] Data types and transfer protocols (FTP, Sockets, HTTP, RMI)
        
    - [ ] Data security and storage (e.g., RAID10)
        
    - [ ] Email systems (understand SMTP basics)
